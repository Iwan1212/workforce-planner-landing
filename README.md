# Workforce Planner — Landing Page

Landing page for the Workforce Planner project, built with React, TypeScript, Vite, and Tailwind CSS.

Design created in Pencil, implemented as a dark-theme SaaS landing page.

## Tech Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- shadcn/ui
- lucide-react icons

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
