# Workforce Planner — Landing Page

Landing page for the Workforce Planner project, built with React, TypeScript, Vite, and Tailwind CSS.

## Tech Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- shadcn/ui
- lucide-react icons

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Deployed on Netlify: https://workforce-planner-patryk.netlify.app
